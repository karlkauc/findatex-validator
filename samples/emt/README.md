# EMT V4.3 example files

Generated by `tools/build_emt_samples.py`. The showcase file is the demo
behind *"No file at hand? Try an example"*; the numbered files are
one-rule-family-each regression fixtures. EMT cross-field rules are not
yet encoded (see `EmtRuleSet` TODO), so only mechanical rule families
are exercised here.

| File | What it demonstrates |
|------|----------------------|
| `00_showcase.xlsx` | **The demo file.** 25 share classes across four products (the same fund range as the EET and EPT showcases), with MiFID II target-market answers and ex-ante/ex-post cost blocks that vary by risk profile and share class. Nine curated defects: bad ISO dates, a non-ISO currency, an out-of-list code type, a holding period that is neither a number nor V/S/M/L/H, a non-numeric ongoing cost, and three missing mandatory cells. |
| `01_clean.xlsx` | All 40 M-flagged fields populated. |
| `02_missing_mandatory.xlsx` | Blanks NUM=5, 11, 12, 15, 16 → PRESENCE/* errors. |
| `03_bad_formats.xlsx` | Invalid ISO 8601 datetime / date, non-ISO-4217 currency, non-Y/N reporting flag. |

Open via `mvn javafx:run` → EMT tab → *Browse…* or run `mvn -Dtest=EmtExampleSamplesTest test`.
