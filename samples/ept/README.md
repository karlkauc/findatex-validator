# EPT V2.1 example files

Generated by `tools/build_ept_samples.py`. The showcase file is the demo
behind *"No file at hand? Try an example"*; the numbered files are
one-rule-family-each regression fixtures. EPT cross-field rules are not
yet encoded (see `EptRuleSet` TODO), so only mechanical rule families
are exercised here.

| File | What it demonstrates |
|------|----------------------|
| `00_showcase.xlsx` | **The demo file.** 25 share classes across four products (the same fund range as the EET and EMT showcases), with PRIIPs KID data: SRI/MRM per risk profile, the four performance scenarios scaled to that risk, cost blocks and the narrative fields. Nine curated defects: bad ISO dates, a non-ISO currency, an out-of-list code type, a liquidity risk outside {M, I, L}, a non-numeric ongoing cost, and three missing mandatory cells. |
| `01_clean.xlsx` | All 66 M-flagged fields populated. |
| `02_missing_mandatory.xlsx` | Blanks NUM=4, 9, 16, 17, 18 → PRESENCE/* errors. |
| `03_bad_formats.xlsx` | Invalid ISO 8601 datetime / date, non-ISO-4217 currency, non-Y/N reporting flag. |

Open via `mvn javafx:run` → EPT tab → *Browse…* or run `mvn -Dtest=EptExampleSamplesTest test`.
