## About

The FinDatEx Validator is a private, open-source project with no advertising and no paid plans. The source code is
on [GitHub](https://github.com/karlkauc/findatex-validator).

**Not an official FinDatEx tool.** The project is not affiliated with, endorsed by or connected to the FinDatEx
initiative or any of its member organisations. The name is used only to describe the templates the tool works with.
